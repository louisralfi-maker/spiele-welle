# Look 2 "farbig-düster" (ART-look2.md "Palette", 09.11.2026 evening): deep blue nights, warm orange fire, dark green
# firs, muted but colourful. Every old name is kept, so every painter and grid still works; the values moved toward the
# direction and 17 colours are new (night blues, fir greens, mist, moor, the creatures' cold eye light).
# Tags:
#   emissive        the fire ramp and the creatures' glow; pixelart.py never maps painted albedo onto these unless
#                   --allow-emissive (the engine draws flames and glow as separate emissive sprites)
#   match=#RRGGBB   the colour's value before look 2. pixelart.py convert matches paintings against it by default, so
#                   every existing sprite keeps exactly its palette indices (its zones, fills and remaps were tuned on
#                   them) and only its colours change; new paintings pass --match new
#   new             added for look 2
#   swap            the composed portraits' swap ramps (SPRITES.md "M3"); pixelart.py never maps a painting onto
#                   these unless --allow-swap, and only the composed portrait parts use them (the code maps each
#                   ramp to the petitioner's target ramp, so their values never move with a look)
# Fixed: night0, night1 and ink are the window glass colours Shaders.metal (lh_is_glass) and mock.py (GLASS) light
# inside window masks; they keep their values until the engine port moves the glass test.
# Painted art is ALBEDO: evenly lit daylight colours. The engine adds dusk, night, firelight and fog.
