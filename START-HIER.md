# Spiele-Welle: so startet der neue Chat

1. **Chat öffnen:** In der Claude-App erscheint im Piston-Empire-Chat ein Kärtchen „Spiele-Welle starten“. Ein Tipp darauf öffnet den neuen Chat in diesem Ordner.
   Ohne Kärtchen: In der Claude-App eine neue Code-Sitzung öffnen, als Ordner **Schreibtisch → Spiele-Welle** wählen und schreiben: **„Los, lies CLAUDE.md und fang an.“**
2. **GitHub-Repo anlegen**, sobald der Chat danach fragt (er zeigt dir die Knöpfe): auf github.com rechts oben **„+“ → „New repository“**.
   - Name: **spiele-welle**
   - **Public** auswählen
   - Kein README, keine Lizenz
   - **„Create repository“** antippen
3. **Schlüssel eintragen:** Danach bittet dich der Chat, einen Schlüssel im Repo einzutragen: **Settings → Deploy keys → „Add deploy key“**, Häkchen bei **„Allow write access“**. Den Text dafür gibt dir der Chat. Das ist kein Passwort.
4. **Später:**
   - Einmal einen App-Store-Schlüssel erstellen. Der Chat führt dich hin, die Datei schickst du nie in den Chat.
   - Vor jedem Einreichen fragt dich der Chat kurz nach deinem Go.

Gebaut wird auf GitHubs Mac. Der alte Mac rechnet nicht, darum stürzt nichts ab.
